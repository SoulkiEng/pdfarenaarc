🛠️ Core Client-Side PDF Utilities

  • Merge PDF — Combine multiple PDFs into one file locally.
  • Split PDF — Extract pages or split PDFs in browser memory.
  • Compress PDF — Shrink PDF byte size while keeping vector text sharp.
  • Redact PDF — Permanently black out SSNs and account numbers locally.
  • Unlock PDF — Strip password restrictions from bank e-statements before portal upload.
  • Sign PDF — Add electronic signatures in-browser without cloud tracking.
  • Grayscale PDF — Convert color scans to black-and-white for smaller portal uploads.
